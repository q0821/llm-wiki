# 多系統命理交叉分析：提示詞模板（備忘）

**備忘型來源**，離本知識庫主軸（技術/投資/親子）。一份可重複使用的提示詞模板，原始 PDF 存於 `raw/assets/多系統命理交叉分析_提示詞模板.md.pdf`（Google Docs 匯出，約 6900 行含格式）。此頁僅備忘用途與方法，不加個人吸收段。

## 用途

把任一個人的出生資料，跑出「跨系統交叉、找共通結構、標矛盾、可證偽、附來源」的深度命理分析。填入【】區塊後整段貼給**具程式執行能力的 AI**（能跑 Python / `swisseph` 者效果最佳；純語言模型會退化為估算版，準確度下降）。

## 輸入區塊（區塊 A）

- 出生日期、出生時間（註明時區）、出生地點（城市或經緯度）
- 生理性別（影響八字大運排法與紫微大限方向）
- 選填：姓名（納入姓名學時）

## 方法論設定（區塊 B，模板的核心約束）

1. **先算後論**：行星度數、宮位、節氣、換運時間一律用天文曆算精確計算，禁止憑記憶估算；有程式能力則用 `pyswisseph`（回歸＋恆星黃道雙套、Placidus / whole-sign 宮位、nakshatra、Vimshottari 大運、八字日柱固定錨點驗算等）
2. **交叉，不並列**：核心是找「多個獨立系統共同指向的同一結構」，三系統以上匯流才算高信度
3. **矛盾要攤開**：系統衝突須明指，並辨別「真實對立」vs「座標系／流派差異的假衝突」，禁止和稀泥
4. **可證偽優先**：結論寫成可用當事人實際紀錄核對的命題，避免巴納姆句
5. **逐句標來源**：每個結論標註由哪些系統支持，不確定處標「⚠不確定」，不得為完整而編造

## 備註

> 方法論上有個有趣的對照：這份模板的五條約束（先算後論、交叉匯流、攤開矛盾、可證偽、逐句標來源）與本知識庫 CLAUDE.md 的「矛盾並列」「信心標注」「原文引用」原則同構——不論主題是命理還是技術，「多來源交叉 + 標矛盾 + 可溯源」是通用的知識可信度框架。此為備忘附記，非論點型吸收。
