## 工作流偏好（依直播揭露）

- **技術棧**：React + Vite + Tailwind CSS
- **流程習慣**：
  1. 用 [[Claude-Design]] 做 0→1 探索
  2. 透過「Hand off to Claude Code」轉到 [[Claude Code]] 做產品化
  3. 透過 [[Figma]] [[MCP]] 雙向同步設計與程式碼
  4. 接手專案先建環境 + [[CLAUDE-md|CLAUDE.md]]，再開始改設計
- **CLAUDE.md 規則範例**：
  - 「跟 Figma 同步時必須使用已定義的 design token」
  - 「必須使用既有 component，沒有定義就先問我」

## 核心觀點

- 設計師的價值不在「產出畫面」本身，而在「判斷這個畫面好不好、有沒有商業/體驗價值」
- AI 時代設計師職涯的弔詭處境：工具讓產出變快，但品味與判斷力反而需要更多刻意練習
- 反對綁定工具的自我定位（「我會用 Figma 我就是厲害的設計師」）
- [[Claude-Design]] 是 0→1 工具，產品化要轉 [[Claude Code]]——明確的工具分工立場
