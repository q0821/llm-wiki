# 行銷快手 Windows — 房仲/車仲 Facebook 自動群發工具

> 來源：廠商官方 YouTube 教學影片「2025 最新版 行銷快手WINDOWS【專屬房仲/車仲業務使用】」

## 一句話定位

把房仲/車仲的物件，**自動群發**到 Facebook Marketplace + 大量 FB 社團的桌面自動化機器人（auto-posting bot）。Windows 主打，亦有 Mac 版。本質是一個**持有使用者臉書登入態、驅動自動化瀏覽器批量發文**的工具。

## 運作架構（技術手法拆解）

| 階段 | 操作 | 技術本質 |
|------|------|----------|
| 1. 安裝 | 下載桌面程式 → 解壓「Facebook Post」資料夾（附教學影片）；執行時「請勿關閉該程式及網頁」 | 桌面殼 + 內嵌/外控瀏覽器自動化；程式存活期間維持瀏覽器 session |
| 2. 程式登入 | 點藍色登入 → 登入 **Google 帳號** | 工具自身的帳號/授權系統（推測綁授權驗證、計費） |
| 3. 臉書綁定 | 輸入臉書帳密 → 程式自動開「視窗」輸入帳密登入 → 觸發「裝置批准通知」→ 手機臉書點登入通知按「是」→ 自動「信任此裝置」→ 自動讀取社團 | **代持登入態**：自動化瀏覽器持有 FB session cookie；信任裝置降低後續重複驗證 |
| 4. 文案設定 | 拍賣文案：商品名稱（系統內名）、社團顯示名、價格（僅數字、勿全形）、狀況、圖片、商品介紹 | 結構化貼文範本 |
| 5. 社團管理 | 建社團列表 → 導入該帳號可見社團（關鍵字搜尋、勾選）→ 全選 | 枚舉使用者已加入社團，批次目標清單 |
| 6. 發文設定 | 選文案 + 每篇間隔時間 + 自動加發文時間（前/後）+ 是否發到一般社團 | 排程/節流參數 |
| 7. 立即執行 | 自動上架 Marketplace（自動填文案+圖片）→ 自動發布 → 在「更多地方上架」勾拍賣社團 → 跳一般社團發文 → 自動點發布 → **預設 60 秒跳下一社團** | 全自動 UI 操作流水線；「請勿操控此視窗」= 前景驅動瀏覽器 |
| 8. 排程執行 | 每天自動發；「間隔時間模式」/「客製化時間模式」（選日期 + 時段 + 社團數量、推薦一天發完） | 無人值守排程 |

## 反偵測 / 反封號手法（核心觀察）

這是「能不能自製」最關鍵、也最敏感的部分——工具的價值有很大一塊在**規避 Facebook 偵測**：

1. **頻率節流**：每篇間隔時間可調（預設 60 秒/社團），明確建議「勿一次調太低」「慢慢調整」→ 規避高頻發文偵測。
2. **重複上架規避**：上架後「**自動刪除紫色圖片，防止臉書偵測重複上架**」→ 推測為某種偵測標記/視覺指紋的規避手法（同一物件跨多社團重複貼，FB 會判 spam/重複內容）。
3. **持久信任裝置**：「信任此裝置」+ 維持 session → 降低重複登入觸發的風險控管。

## 風險警示（與操作事實並列）

> 依 CLAUDE.md「矛盾/風險並列呈現，不擅自取捨」。以下風險廠商教學影片**未提及**（賣方敘事偏誤）：

- **違反 Facebook 平台條款**：FB Terms / Platform Policy 明文禁止以自動化手段（automated means）存取、發文、規避技術性偵測措施。本工具三項手法（自動登入、批量自動發文、刪圖規避重複偵測）皆直接踩線。
- **封號風險**：帳號可能被限速、停權、永久停用；社團可能被踢、被檢舉。房仲常以個人/品牌經營，封號 = 商譽與客源資產一次歸零。
- **帳密交付風險**：把臉書帳密輸入第三方桌面程式 = 把帳號完整控制權交給工具方。帳密可被濫用、外洩、或做未告知的操作（無從稽核）。
- **spam / 商譽風險**：同物件大量群發社團，易被社團管理員與成員檢舉、傷品牌信任。
- **法遵風險**：依地區可能涉及個資、廣告不實、房仲業揭露規範等。

## 關聯

- 共同構成「自動化操作瀏覽器」家族——行銷快手是其中**最靠近合規紅線**的應用案例。

## 可行性評估摘要

> 匯入動機：廠商詢問使用者「有沒有辦法做出一樣的產品」。完整評估（技術架構 + 合規版 + 廠商談判要點）另存於本地案件目錄，不入公開 wiki；此處僅留結論錨點。

- **技術可行性：高**。核心是瀏覽器自動化（Playwright/Puppeteer）+ session 管理 + 排程 + 文案/圖片範本 + 社團枚舉。對有自動化經驗的團隊不是難題。
- **真正門檻不在技術，在「反偵測軍備競賽」+ 合規/法律風險承擔**：FB 持續更新偵測（行為指紋、頻率、重複內容、自動化特徵），維護反偵測是無止境的貓抓老鼠；且產品本身協助違反 FB ToS，平台可發 C&D、封 App、究責。
- **建議**：若要接這案，務必先界定**風險歸屬**（帳號封禁、法律責任由誰承擔）與**定位選擇**（做純灰產群發 vs 轉做合規路線：FB 官方 Marketing API / 廣告投放 / 房仲 CRM 串接）。詳見對話。
