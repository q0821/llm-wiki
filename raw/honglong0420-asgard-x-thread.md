# Asgard Skills 263 個 agent skills 開源推廣（X 推文）

主要是講
https://github.com/asgard-ai-platform/skills

老闆之前很瘋狂，想要整理了一份台灣中小企業日常工作場景用得上的 agent skills 放到公司 GitHub 上。

辯證法、商業模式九宮格、精實創業、敘事這些方法論，前沿的 LLM 幾乎都內建了。缺的不是 AI 知不知道，而是人不會記得主動把它叫出來。會議開到一半、定價拍腦袋的當下，沒人會停下來說「等等，我們來論述一下正論反論合論」。

把方法論寫成 skill，差別就在這裡：變成可以工程化的東西。同一支 skill，每次叫出來都跑一樣的步驟、輸出一樣的格式。可 reuse、可 rerun，能被版本控制，這才是 skill 的價值。

整包 263 份、22 個分類，全部 MIT 開源。涵蓋電商、行銷、財會、客服、人資、製造、法務這些中小企業天天碰到的領域，也有勞健保、營業稅這類台灣才需要處理的業務。

特別推薦其中四支可以串成完整路徑的「思維模型技能」：

① **hum-dialectics**（辯證法）：團隊吵路線、老闆在兩個方向間搖擺時，叫 AI 跑一輪正反合。鐵律：**Synthesis ≠ Compromise**，各退一步不算解答，重新 frame 問題才算。

② **ops-business-model-canvas**（商業模式九宮格）：方向定了，逼 AI 把九格全填滿，檢查價值主張、客群、營收、成本之間的故事能不能兜起來。**漏一格就是許願。**

③ **ux-lean-startup**（精實創業）：模式不能紙上談兵。列出風險最高的假設，做最小可行測試。決定 pivot 還是 persevere，直接逼你看數據。

④ **hum-narrative**（敘事方法論）：前面跑完後，還得在論述敘事上說服董事、員工、客戶、投資人。鐵律：**Every Story Needs Tension**。沒衝突的不是故事，是報告。

這四支串起來，重點不是 AI 多懂方法論，而是這套方法論終於可以按一個鍵就跑一遍，不會因為你那天太忙或太自信偷懶略過。
